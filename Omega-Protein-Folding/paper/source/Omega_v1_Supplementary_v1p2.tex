\section{Reproduction (analysis-only)}
This evidence pack regenerates figures/tables from saved CSV outputs (it does \emph{not} rerun the Omega engine).
\begin{verbatim}
python -m venv .venv
source .venv/bin/activate
pip install -r scripts/evidence_v1/requirements.txt

python scripts/evidence_v1/make_figures.py --outdir figures_repro
python scripts/evidence_v1/make_tables.py  --outdir tables_repro
\end{verbatim}
