\subsection*{Multi-scale symbolic certificate metrics (Fold\_m on binary readouts)}
\begin{itemize}
  \item Protocol: define a binary readout $\rho(t)\in\{0,1\}$ and compute sliding windows $\omega_t^{(m)}$ of length $m$; stabilize each window via $\mathrm{Fold}_m:\{0,1\}^m\twoheadrightarrow X_m^{\mathrm Z}$ (no adjacent 11), producing a stable-type stream $x_t\in X_m^{\mathrm Z}$.
  \item Readouts used in this repository:
  \begin{itemize}
    \item $\rho_A(t)$ from perp-space: with $w_0=\mathrm{mean}(y^\perp)$ and fixed $u=(1,0,0)$, define $s_t=u\cdot(y^\perp_t-w_0)$ and binarize via a robust threshold (default $b_t=1\{s_t\ge \mathrm{median}(s)\}$; ablations use mean or zero threshold).
    \item $\rho_B(t)$ from 6D steps: from $\Delta n_t=n_{t+1}-n_t$, binarize by majority sign across coordinates (deterministic tie-break).
  \end{itemize}
  \item Metrics: empirical entropy of stable types $H(\mathrm{type})$, support size, run-length statistics on the raw bitstream, and a practical SMB-style entropy-rate proxy (block-entropy slope).
  \item Null families: in addition to random-chain and perturbed-native controls, we include bond-direction shuffle and block-shuffle controls (preserve per-bond lengths and marginal directions while destroying long-range correlation; configured via \texttt{--shuffle-reps}, \texttt{--blockshuffle-reps}, \texttt{--blockshuffle-k}).
  \item Hybrid full1k run (recommended audit entrypoint): run directory and plots are provided in the evidence repository under \texttt{docs/runs/}.
  \item Outputs (large CSVs are under \texttt{data/processed/pdb\_bench/} and reports under \texttt{artifacts/reports/}):
  \begin{itemize}
    \item Report: \texttt{artifacts/reports/pdb\_*\_stats\_n1000\_seed0\_*.md} (exact tag depends on null configuration)
    \item Samples CSV: \texttt{data/processed/pdb\_bench/*\_stats\_samples\_n1000\_seed0\_*.csv}
    \item Summary CSV: \texttt{data/processed/pdb\_bench/*\_stats\_summary\_n1000\_seed0\_*.csv}
    \item Figures: generated by plotting scripts under \texttt{scripts/pdb\_bench/}.
  \end{itemize}
\end{itemize}
