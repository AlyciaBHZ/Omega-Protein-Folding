\section{Data and code availability}

All experiment outputs (CSVs, audit logs, plots) and analysis scripts used to generate the figures and tables are included in this repository. The project is open-source at \href{https://github.com/AlyciaBHZ/Omega-Protein-Folding.git}{\texttt{https://github.com/AlyciaBHZ/Omega-Protein-Folding.git}}.

Paper-facing assets and their sources are organized as follows:
\begin{itemize}
  \item \texttt{paper/assets/figures/}: manuscript figures as \texttt{fig\{N\}.png} (Fig.~\ref{fig:1}--Fig.~\ref{fig:12}).
  \item \texttt{paper/assets/tables/}: manuscript tables as \texttt{table\{N\}.tex} (Table~\ref{tab:1}--Table~\ref{tab:4}).
  \item \texttt{figures/}: additional plots referenced by the Blind Sprint section (e.g. Fig.~\ref{fig:13}).
  \item \texttt{data/processed/}: CSV summaries referenced by the manuscript (including $\theta^\star$ feasibility and Sprint A/B summaries).
  \item \texttt{artifacts/reports/}: per-experiment narratives, audit interpretations, and reproduction tables/figures.
\end{itemize}

This LaTeX manuscript is maintained under \texttt{paper/}. Project-level licensing and attribution guidance is documented in \texttt{LICENSE} and \texttt{docs/covenant\_en.md}.
