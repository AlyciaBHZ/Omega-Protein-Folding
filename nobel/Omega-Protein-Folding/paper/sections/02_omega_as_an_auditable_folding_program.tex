\section{PhasonFold as an auditable folding program}

PhasonFold treats folding as a discrete dynamical process with explicit state, moves, and an append-only audit trace. A candidate structure is generated by applying a move sequence to a discrete state; each proposal is evaluated by a readout (e.g., contacts, distogram residuals, or physical gates) and either accepted, rejected, or relaxed by a projector-style update. The full run is recorded as an audit trace containing move identities, accept/reject decisions, phason violations, and slice-offset relaxation events ($\Delta w_0$). This design supports mechanism-level A/B tests (e.g., phason gating, alphabet expressivity, nonlocal-move policies) with precise attribution.
